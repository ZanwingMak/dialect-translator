# 🗣️ 方言翻译器 (Dialect Translator)

一个支持多种中文方言的语音转文本、文本翻译、语音合成工具。由 **OpenClaw AI** 编写。

## ✨ 支持的语言/方言

- 🏠 **雷州话** - 广东雷州半岛方言
- 🇭🇰 **粤语** - 广东/香港方言
- 🗣️ **客家话** - 梅州/惠州方言
- 🇹🇼 **闽南语** - 福建/台湾方言
- 🇨🇳 **吴语** - 上海/浙江方言

## ✨ 功能特点

- 🎙️ **语音识别** - 录音自动识别方言文字
- 🌐 **智能翻译** - 支持任意两种语言互译（使用 OpenAI GPT）
- 🔊 **语音合成** - 翻译结果转语音播放
- 📋 **历史记录** - 保存最近 50 条翻译
- 🔒 **本地存储** - API Key 保存在本地

## 🚀 快速开始

### 安装依赖

```bash
cd dialect-translator
npm install
```

### 开发模式

```bash
npm run dev
```

访问 http://localhost:3003

### 生产构建

```bash
npm run build
```

## 📋 使用说明

1. **设置 API Key**
   - 需要 OpenAI API Key（用于 Whisper 语音识别和 GPT 翻译）
   - API Key 保存在浏览器本地，不会上传

2. **选择语言**
   - 从下拉菜单选择源语言和目标语言
   - 支持预置方言和自定义选项

3. **录音翻译**
   - 点击 🎤 按钮开始录音
   - 再次点击停止录音
   - 自动识别文字并翻译

4. **语音播放**
   - 点击 🔊 按钮播放翻译结果

## 🛠️ 技术栈

- Vue 3 + Vite
- TailwindCSS
- OpenAI API (Whisper + GPT + TTS)

## 📝 依赖说明

本工具依赖 OpenAI API：
- **Whisper** - 语音识别（支持中文）
- **GPT** - 方言翻译
- **TTS** - 语音合成

## ⚠️ 注意事项

- 方言识别准确度因语言和录音质量而异
- 建议在安静环境下录音
- 首次使用需要设置 OpenAI API Key
